# Contributing

Technical Debt is community-shaped. Suggest a future discussion through the [topic issue form](https://github.com/numerate64/technicaldebt/issues/new?template=suggest-a-topic.yml), or open a pull request for a correction to this site.

Please keep suggestions specific enough to prompt a useful one-hour conversation, welcoming to different levels of experience, and free of vendor pitches. Read the [community guidelines](CODE_OF_CONDUCT.md) before participating.
