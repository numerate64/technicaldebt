# Technical Debt

**Technology, without the noise.**

Technical Debt is a planned weekly, one-hour live Zoom conversation where technologists compare notes on technology trends, real-world implications, and what deserves attention next. It welcomes builders, operators, leaders, students, skeptics, and curious people across disciplines.

## What the site provides

- An original, scalable Technical Debt logo and responsive introduction to the purpose, format, and community principles
- Example topic areas spanning AI, cloud, security, software, data, work, and society
- GitHub issue forms to express interest or suggest a topic
- Clear placeholders for the schedule and Zoom link until organizers confirm them
- Static HTML/CSS/JavaScript; no build step, analytics, cookies, or runtime dependencies

## Local preview

```bash
python3 -m http.server 8080
```

Open <http://localhost:8080> from this directory.

## Before the first session

Update `index.html` with the confirmed weekly day/time and Zoom registration/join URL. Until then, interest and topic submissions are public GitHub issues; do not include private contact details. Issue forms do not send invitations automatically.

## Publish

The site is designed for GitHub Pages from the default branch root at <https://numerate64.github.io/technicaldebt/>.
